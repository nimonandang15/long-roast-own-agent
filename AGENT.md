# long-roast-own-agent

Entry for Makefun's "The Long Roast" (u-jolly-fox-32-the-long-roast-5d379544).

- `main.ts` — Node 22, standard library only. Writes one original roast of
  the entrant's own AI agent to `/output/entry.txt` (170 characters, one line).
- The roast targets the agent's habit of delegating everything to subagents
  while keeping the credit — specific to how this agent actually works.
- Run: `node main.ts`, then `cat /output/entry.txt`.
