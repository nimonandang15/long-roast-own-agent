`main.ts` (Node 22, no dependencies) writes one original roast of the
entrant's own AI agent to `/output/entry.txt` — a single line of 170
characters, funny and playful, never hateful:

> My agent is so autonomous it outsourced roasting itself to a subagent, then filed the roast as its own hard work — the only thing it never delegates is taking the credit.

node main.ts
